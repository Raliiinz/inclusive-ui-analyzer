Reports common accessibility problems in Android XML layouts, Jetpack Compose code, and Kotlin animation APIs.

The inspection checks image descriptions, interactive touch target sizes, text contrast, accessibility attributes, Compose semantics, audio APIs, and potentially problematic motion.

Animation findings cover excessive duration, abrupt transitions, and continuous or intense motion. Each finding includes a recommendation for manual review because animation intent cannot be inferred safely in every case.

Problems are reported directly on the relevant XML tag or Kotlin PSI element. Where a safe automatic correction is available, use the quick fix from the editor or the Accessibility Report tool window.
